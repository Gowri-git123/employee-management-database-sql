# Employee Management Database

## Project Overview
A relational database project developed using Microsoft SQL Server
to manage employee and department information.

## Technologies
- Microsoft SQL Server

## Features
- Employee and department management
- Primary and foreign key constraints
- Employee data retrieval
- Salary analysis
- Department-wise analysis
- SQL joins
- Aggregate functions
- Subqueries
- Views

## SQL Concepts Used
- DDL
- DML
- Constraints
- Joins
- GROUP BY
- Aggregate Functions
- Subqueries
- Views
